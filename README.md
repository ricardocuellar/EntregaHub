# EntregaHub — recursos de inicio

Aplicación de entregables privados con colaboradores, versiones, comentarios y aprobación. Backend Django REST Framework; frontend React/TypeScript. Administrador, colaborador y cliente.

## Qué contiene este paquete

- SPEC.md: comportamiento y criterios esenciales.
- PERMISOS.md: quién puede hacer qué y en qué proyectos.
- ESTADOS.md: revisión, decisiones, conservación y reintentos.
- TAREAS.md: bloques de trabajo, inicialmente pendientes.
- AGENTS.md: procedimiento de trabajo con IA.
- RECORRIDO.md: escenario ficticio para explicar el producto.


## Estado

Paquete documental: todavía no contiene backend/, frontend/, manage.py, package.json, contenedores o aplicación ejecutable. No ejecutar pip, npm, migrate o Docker esperando que arranque. El starter de la siguiente sección traerá los comandos comprobados.

## Fuentes y versiones

El alcance viene del plan vigente y de la restauración explícita de colaborador, versiones y aprobación. No usar recursos antiguos de dos roles/sin versiones. Dependencias y comandos finales se verifican con el prototipo. No se ha publicado ni probado una aplicación con este paquete.
